# 🐍 Mayuri Kurhe — Developer Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript. It presents my work as a Backend Python Developer (Python, Django, REST APIs) based in Pune, India.

## 👩‍💻 About

I'm **Mayuri Rajendra Kurhe**, a Software Developer (Python & Java) with a BCA (9.0 CGPA, top 5%) and an MCA (8.53 CGPA). I completed a 6-month Python/Django internship at Anudip Foundation and have deployed apps on AWS (EC2, S3, IAM).

## ✨ Features

- Responsive single-page layout with a mobile menu
- Sections: Hero, About, Skills, Experience, Projects, Certifications, Education, Contact
- Contact form powered by [Web3Forms](https://web3forms.com), so no backend is needed
- No build step and no dependencies beyond Google Fonts and Font Awesome (CDN)

## 🛠️ Tech Stack

| Layer | Technologies |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (custom properties, grid, flexbox) |
| Scripting | Vanilla JavaScript |
| Fonts / icons | Google Fonts (Syne, DM Sans), Font Awesome 6 |
| Form | Web3Forms API |

```bash
# open index.html in your browser
```

## 📬 Contact Form

The form posts to Web3Forms using an access key in `index.html` (`WEB3FORMS_KEY`). These keys are meant to be public, so restrict yours to your site's domain in the Web3Forms dashboard.
